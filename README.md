# CI/CD Pipeline with Jenkins, Docker & AWS 🚀

A hands-on CI/CD project where I explored and implemented an automated pipeline for a MERN application using different DevOps tools.

This project was built while learning CI/CD concepts and understanding how the different tools work together in a real deployment workflow.

## 🔧 Tools & Technologies

* **Git & GitHub** – Source Code Management
* **Docker** – Application Containerization
* **Jenkins** – CI/CD Pipeline Automation
* **SonarQube** – Code Quality Analysis
* **OWASP Dependency-Check** – Dependency Security Scanning
* **Trivy** – Container & Filesystem Scanning
* **Argo CD** – GitOps-based Continuous Deployment
* **Kubernetes** – Container Orchestration
* **AWS EKS** – Kubernetes Deployment
* **Helm** – Kubernetes Package Management
* **Prometheus & Grafana** – Monitoring

## 🏗️ What I Worked On

* Set up Jenkins for CI/CD automation
* Created Docker images for the application
* Integrated SonarQube for code quality checks
* Added OWASP dependency scanning
* Used Trivy for security scanning
* Worked with Jenkins pipelines for build and deployment stages
* Configured Argo CD for GitOps-based deployment
* Worked with Kubernetes resources and deployments
* Explored AWS EKS for running the application
* Added Prometheus and Grafana for basic cluster/application monitoring

## 📌 Project Flow

The project helped me understand how source code moves from **GitHub → Jenkins → Docker → security/quality checks → GitOps → Kubernetes**.

I also worked through different configuration and deployment issues during the setup, which helped me understand the practical side of CI/CD instead of only learning the concepts.
